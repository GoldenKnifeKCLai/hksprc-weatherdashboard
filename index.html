官方、政府及其他數據 API 來源

本儀表板使用香港天文台開放數據、Open-Meteo 第三方天氣預報 API，以及 OpenFreeMap／MapLibre 開源地圖技術。各來源的覆蓋範圍、更新頻率、服務承諾及資料性質並不相同；HKSCN 地點的天氣數值為座標附近的模型預報，並非碼頭現場儀器讀數。

香港天文台個人版網站 (Personalised Website) 資料一線通 (DATA.GOV.HK 天氣數據集) 香港天文台開放數據簡介 API (Open Data API) Open-Meteo 天氣預報 API（第三方模型資料） OpenFreeMap（開放地圖底圖服務） MapLibre GL JS（開源互動式地圖程式庫） OpenFreeMap 自行託管文件（提升營運控制）
營運可靠性提示：OpenFreeMap 公共服務按「現況提供」，不保證服務等級（SLA）。若此地圖是每日營運關鍵工具，建議評估自行託管地圖服務，或選用提供正式 SLA／支援合約的地圖供應商。MapLibre 是開源前端程式庫，本身不提供地圖資料託管或 SLA。
